# Credits

Epic Motion Sites combines ideas from the projects below. Everything here is written in our own words; no code or text was copied.

| Source | License | What we took |
|---|---|---|
| [nateherkai/scroll-craft](https://github.com/nateherkai/scroll-craft) | MIT | The ideas of a feeling curve, a single peak, a signature move, a refuse list and automated page walking. Rewritten for a lighter single-file workflow (`references/craft.md`, `scripts/verify.py`). |
| [greensock/gsap-skills](https://github.com/greensock/gsap-skills) | MIT | Recommended companion skills. `references/gsap.md` defers to them for API details. |
| [GSAP](https://gsap.com) | GSAP standard license (free, incl. commercial) | Optional engine for complex sites, loaded from a CDN. |
| [Lenis](https://github.com/darkroomengineering/lenis) | MIT | Optional smooth scrolling. |
| [anthropics/skills](https://github.com/anthropics/skills) | Apache-2.0 | The Agent Skills format (`SKILL.md` + references/scripts/assets). |
| [studio.motionsites.ai](https://studio.motionsites.ai/explore) | — | Inspiration only. We studied the patterns; no images, logos, copy or code were used. |
